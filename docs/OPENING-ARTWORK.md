# Opening artwork

The opening is a handcrafted paper-theatre still life created on 19 September 2026 from the supplied paper-theatre reference. It is a visual introduction only, not a depiction of the wedding venue or an account of travel.

## Production derivatives

- `public/images/opening-paper-theatre-desktop.webp`: 16:9 warm tabletop with an oxblood-bound book, paper theatre, Hong Kong-inspired harbour, bridge, mountains, florals, and an antique-gold route.
- `public/images/opening-paper-theatre-mobile.webp`: independently composed 9:16 version that keeps the title plaque and lower page clear instead of cropping the desktop artwork.

Both artworks deliberately contain no lettering, initials, dates, venues, people, photographs, logos, or watermarks. The invitation copy is live HTML so it stays crisp, accessible, and easy to change. The button, focus state, transition, screen-reader description, and reduced-motion fallback are implemented in React and CSS rather than baked into the artwork.

The generated PNG source files remain in the Codex generated-image store. The optimised WebP derivatives above are the project assets. Original supplied photographs remain preserved and are not used by this opening.
