# Destination postcard artwork

Created on 6 September 2026 using ChatGPT's built-in image generator, one image per destination. Custom generated destination illustrations replace the earlier map crops. No couple portraits or map snapshots are used. Original generated PNGs remain under the Codex generated_images directory; optimized 960 × 640 WebP copies live in `public/images/postcard-*-illustrated.webp` and are used in both the gallery and composer.

## Art direction / exact shared prompt

Use case: illustration-story. Create one finished landscape 3:2 destination postcard illustration for a premium wedding invitation website. Destination scene: {SCENE}. Consistent collection style: beautifully art-directed mid-century travel lithograph with hand-painted gouache detail, subtle printed paper grain, elegant architectural drawing, inviting sunlight, sophisticated muted terracotta/oxblood, antique gold, creamy ivory, sage and dusty turquoise. Richly colored scenic artwork, not monochrome pencil sketch. One coherent scene occupying the entire image edge to edge. Real recognizable destination, tasteful composition with clear foreground/middle/background, collectible and romantic yet architectural. No people, no couple, no portraits. No lettering, captions, words, numbers, border, stamps, logos or watermarks: typography will be added in the website. Not a mockup: only the flat artwork image itself.
